材质 / Shader 导出

入口 MaterialFile → MetarialUitls.WriteMetarial 格式 LAYAMATERIAL:04（.lmat） 查表配置 MetarialPropData.json
本章思路：材质导出的核心是按 shader 名查表映射：① 先以 shader 名查到对应的映射配置，据此逐类映射 → ② 渲染状态、③ 贴图、④ 颜色（HDR 需分解）、⑤ 基础类型（含条件规则）、⑥ defines 宏 → ⑦ 天空盒为特例，单独导出 .cubemap。
本页实测材质：Ellen_Body_Mat（Standard shader）来自 Unity 官方免费示例 3D Game Kit Lite；天空盒为 6 面天空盒 6SidedFluffball。
本页梳理 ① 按名查表 ② 渲染状态 ③ 贴图映射 ④ 颜色 + HDR ⑤ 基础类型 + 条件规则 ⑥ defines ⑦ 天空盒

① 按 shader 名查表

MetarialPropData.json

本节是总纲——先按 shader 名查到映射配置，决定后续映射方式。 WriteMetarial 用 material.shader.name 查 MaterialPropsConfigs： 查到就按配置导出；查不到时：未启用自定义 Shader 导出则跳过该材质，启用则转交 自定义 Shader 导出。

实测 Ellen_Body_Mat 是 Standard，配置把它映射为 Laya 的 PBR 材质类型：

Standard 配置含 8 个贴图槽（_MainTex→u_AlbedoTexture、_BumpMap→u_NormalTexture、 _MetallicGlossMap、_EmissionMap、_OcclusionMap…）+ 颜色 + float + 条件规则。 已配置的 shader 类型：Standard/PBR、BlinnPhong、Unlit、Skybox 系、PARTICLESHURIKEN。
自定义 Unity Shader 也可以走这张表：以完整的 material.shader.name 作为 JSON key， targeName 填 Laya 端已存在的 Shader 名称。此方式只导出材质参数和资源引用，不会生成 Laya Shader 源码； 没有登记的 Shader 才会在启用开关后进入自动转换流程。
项目级配置：Unity 项目可在任意 Editor 特殊目录下创建 Assets/**/Editor/LayaAir/MaterialMappings.json，例如 Assets/Game/Editor/LayaAir/MaterialMappings.json。导出器通过 AssetDatabase 查找，因此不要求 Editor 位于 Assets 根层； 同一个项目只能保留一个该名称和目录结构的配置文件，避免产生不确定的覆盖顺序。 插件先加载内置配置，再加载项目配置；同名 Shader 的项目配置会完整覆盖内置条目。 materials 用于普通材质，cpuParticle 用于 CPU 粒子材质，后者未命中时仍回退到普通材质表。 项目配置使用正确拼写 targetName，同时兼容旧拼写 targeName。

② 渲染状态

映射剔除 / 混合 / 深度等渲染状态到 Laya 字段。 写入 s_Cull（剔除）、s_Blend / s_BlendSrc / s_BlendDst（混合因子）、 alphaTest + alphaTestValue、renderQueue、materialRenderMode。 普通材质（本页主题的 Standard/PBR 等）的混合因子经 GetSrcBlend / GetDstBlend 把 Unity 的 _SrcBlend / _DstBlend 整数值用 switch 逐项映射到 Laya 的混合枚举。 （自定义 Shader 与粒子材质走另一条按枚举名映射的路径，不在此处。）

③ 贴图映射

将配置中的各贴图槽映射到 Laya 字段并导出。 遍历配置的贴图槽，material.GetTexture(uName) → 导出 TextureFile → 加入 textures 数组（带 layaName）。 内置资源贴图跳过（unity_builtin_extra 等）；法线贴图标 isNormal。 平铺偏移不是属性类型：新配置在对应 texture 上用 tilingOffset 指定 Laya 字段，旧 tillOffset 数组仍兼容；两者均写为 [scale.x, scale.y, offset.x, offset.y]。

④ 颜色 + HDR 分解

本页重点

普通颜色直接写入；HDR 超亮颜色分解为颜色 + 强度两部分。 普通颜色直接写 rgba；HDR 颜色（如自发光）分量 > 1，超出 0–1 范围，于是 DecomposeHdrColor 把它拆成压缩颜色 + 强度两部分：颜色分量先按最大分量缩放、再夹到上限 0.749（k_MaxByteForOverexposedColor），并经 LinearToGammaSpace 转到 Gamma 空间后写 rgba； 强度是按最大分量反算得出（1 / scaleFactor，不等于 Unity 强度滑杆的原值），单独写到 hdrName（如 u_EmissionIntensity）。

Unity HDR 颜色
RGB(0,143,191) 强度 2 — DecomposeHdrColor → 压缩颜色（≤0.749，Gamma 空间）
+ 反算强度 = Laya 自发光
颜色 + 强度 分离
BlinnPhong 材质若缺高光色，会补默认 u_MaterialSpecular = (0.2,0.2,0.2,1)。

⑤ 基础类型 + 条件规则

新版 properties 显式声明类型，支持 Float、Int、Bool、Vector2、Vector3、Vector4、Color。 Vector2/3 会按实际分量数写入；Bool 写 JSON 布尔值；Color 可用 hdrName 拆分 HDR 强度。 Float 可用 isGamma 转换，所有类型均可复用 rule 条件改名。

Assets/**/Editor/LayaAir/MaterialMappings.json 手动迁移 Shader 的项目配置示例
{
  "materials": {
    "Custom/MyShader": {
      "targetName": "MyLayaShader",
      "textures": [
        { "uName": "_MainTex", "layaName": "u_MainTexture",
          "define": "MAINTEXTURE", "tilingOffset": "u_TilingOffset" }
      ],
      "properties": [
        { "uName": "_Intensity", "layaName": "u_Intensity", "type": "Float" },
        { "uName": "_Mode",      "layaName": "u_Mode",      "type": "Int" },
        { "uName": "_Enabled",   "layaName": "u_Enabled",   "type": "Bool" },
        { "uName": "_Scroll",    "layaName": "u_Scroll",    "type": "Vector2" },
        { "uName": "_Direction", "layaName": "u_Direction", "type": "Vector3" },
        { "uName": "_Params",    "layaName": "u_Params",    "type": "Vector4" },
        { "uName": "_Tint",      "layaName": "u_Tint",      "type": "Color",
          "hdrName": "u_TintIntensity" }
      ]
    }
  },
  "cpuParticle": {}
}

旧版 floats / colors / tillOffset 无需迁移；若新旧配置写入同一个 Laya 字段， properties 的结果优先。旧 float 的 rule 条件改名行为也保持不变：例如有 _MetallicGlossMap 时从 _GlossMapScale 取光滑度。

⑥ defines（宏开关）

按材质实际特性追加宏开关。 下面三类来源各自对应一种触发条件：

来源触发条件
floatValue某 float 等于指定值 → 加宏
TextureValue某贴图存在 → 加宏（如有法线贴图 → NORMALTEXTURE）
keyWorld某 shader keyword 启用 → 加宏
含法线类宏（NORMALTEXTURE / DETAILNORMAL / NORMALMAP）时自动追加 NEEDTBN。

⑦ 天空盒 → .cubemap

仅 6 Sided 出 cubemap

天空盒作为特例单独导出，生成 .cubemap 而非仅 .lmat。 场景天空盒材质若是 Skybox/6 Sided，走 WriteSkyMetarial：把 6 个面的贴图写入一个 .cubemap 文件， 材质 .lmat 的 type 为 SkyBox，引用该 cubemap。

Unity 天空盒 Shader支持导出去向
Skybox/6 Sided✓WriteSkyMetarial → .cubemap（6 面）+ SkyBox 材质
Skybox/Procedural✓普通查表 → SkyProcedural（SkyTint / GroundColor）
Skybox/Panoramic✓普通查表
Skybox/Cubemap✗当前版本未支持单张 Cubemap 天空盒导出 → 跳过，不生成 cubemap
天空盒支持范围：当前版本支持 Skybox/6 Sided（导成 .cubemap）、Skybox/Procedural、 Skybox/Panoramic；不支持单张 Skybox/Cubemap 天空盒。
